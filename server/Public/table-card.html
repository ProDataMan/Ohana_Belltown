Table Cards

Print this page (Cmd/Ctrl+P) to get table-ready cards sized for a standard 4×6" acrylic stand — one per numbered table. Each QR code is unique to its table: scanning it lands on Happy Hour automatically during Happy Hour (Mon–Fri, 3–6pm) or the full menu the rest of the time, and unlocks an "Order" button next to every menu item so a guest can flag staff for something without waving anyone down. Currently set up for 12 tables — ask to add more if Ohana has additional seating to cover.
