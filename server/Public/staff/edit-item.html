Add-Ons & Upgrades

Optional extras a customer can check when placing a table order — e.g. "Add Katsu" or "Yosh Size", priced as the extra amount added to this item's price.

Picking from the catalog fills in the name/price above — tweak the price first if this dish needs a different one (e.g. Yosh Size varies by dish). Adding a new name here also saves it to the catalog for next time.

Required Choices

A required pick built into this dish — e.g. "Choice of Protein: Chicken Teriyaki, Beef Teriyaki" on a bento. Doesn't change the price; the customer must pick exactly one before it can be ordered. For a dish where two versions cost the same (e.g. "Chicken Teriyaki" vs. "Spicy Chicken Teriyaki"), splitting into two separate menu items is usually simpler than a required choice — use this for a choice that's genuinely part of one combo dish.
