How to turn on the automatic import
  1. Log in to the Heartland Restaurant Admin Portal as an owner or manager.
  2. Choose the Ohana Belltown location, then Integrations in the left menu.
  3. Click New (or the + button), set Integration Type to API, make sure Active is checked, and click Save.
  4. Copy the key that appears in the API Key field. Treat it like a password.
  5. If the Integrations page won't create a key, or asks you to pick a partner from a list, contact Heartland Restaurant support and ask for "a location API key for our own reporting integration, read-only access to closed orders and rooms/tables (API v2)". Also ask whether a partner key is required for the API's authentication header; if they give you one, it goes in HEARTLAND_PARTNER_KEY.
  6. Send the key(s) to whoever manages the website server to add as the secrets HEARTLAND_API_KEY (and HEARTLAND_PARTNER_KEY if issued). After the next deploy, this page shows "API connected", the import runs every day at 4:30am, and you can backfill earlier days with the button above.

Upload a CSV export

Works without the API key, and for backfilling. One row per item sold, with at least: an item name, a date/time, and a ticket (check) number or table. Quantity, price, guest count and close time are used if present. Uploading the same days again updates them instead of double counting.

How to export from Heartland
  1. In the Admin Portal, open Reports and choose a ticket-level report that lists each item with its ticket number and table (for example a Ticket Detail or Item Sales by Ticket report; names vary by version).
  2. Set the date range and click Export (top right) → CSV.
  3. Upload the file here. If it's rejected, the message lists the columns it found; send a sample file so the importer can be taught that report's layout.
